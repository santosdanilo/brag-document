# Especialização em Engenharia de IA

**Provider:** Dev + Eficiente
**Status:** In progress

**Description:** Aprenda a desenvolver e integrar soluções de IA em aplicações reais. Domine desde fundamentos até arquitetura e deploy de sistemas inteligentes.

The provider positions the program as training for building systems with **LLMs**, **agents**, and **RAG** that work in production and at real scale.

## Public Curriculum

The provider currently presents the specialization as a 10-module path:

### Foundations

- 01. Introduction and welcome
- 02. Fundamentals of System Retrieval
- 03. Fundamentals of Gen AI
- 04. Fundamentals of RAG

Publicly listed topics include tokenization, vector spaces, TF-IDF, Transformers, the *Attention Is All You Need* paper, and RAG in practice.

### Implementation

- 05. The science behind vector search
- 06. RAG architecture
- 07. AI agent engineering
- 08. Financial market analysis with AI

Publicly listed topics include hybrid search, RRF, ColBERT, semantic chunking, a RAG API, workflows, prompt chaining, routing, parallelization, and memory.

### Production

- 09. Quality and validation in LLM systems
- 10. Additional considerations

Publicly listed topics include layered evaluation with Langfuse, custom and semantic validators with Guardrails AI, optimization, quantization, and multilingual embeddings.

## Main Project

The main project is a financial-market analysis system built incrementally across the modules. It is described as an AI agent that ingests Yahoo Finance news, processes SEC reports, filters retrieval by metadata, produces structured output, and exposes an API consumed by a frontend.

The provider also advertises an additional applied challenge focused on a customer-service system inspired by a restaurant marketplace.

## Intended Audience

The provider targets junior, mid-level, and senior developers, as well as tech leads, staff engineers, and principal engineers making architecture decisions involving AI. The course is described as a better fit for people who already have a software-engineering foundation than for beginners looking for an introductory framework tutorial.
