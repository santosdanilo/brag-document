# Senior Full-Stack Engineer — Sales Engagement SaaS

## About the Company

An established, profitable US-based B2B SaaS company behind a decade-old, revenue-carrying sales-engagement platform for cold email and outreach automation. The team is small and lean. This is the most important engineering hire on the product.

## The Role

A hands-on engineer owns the platform day to day, end to end: backend services, frontend, AWS infrastructure, production debugging, and third-party integrations. Success in the first six months means learning the stack quickly, automating manual work, stabilizing production, and then building what's next. The departing engineer will support a clean handoff.

## What You'll Own

- Own the codebase end to end as the primary engineer: ship features, fix issues, and keep production healthy.
- Automate manual processes that still consume time.
- Root-cause and resolve production incidents in live systems with paying customers, including memory and heap issues, third-party API edge cases, and queue backups.
- Run deploys and infrastructure changes as routine daily work across AWS.
- Build and run AI agent workflows in Claude Code across the repository.
- Take specced work, fill gaps independently, and deliver estimates reliably.
- Scope and build new products from scratch during heavier build cycles.

## What We're Looking For

- 8+ years as a senior full-stack engineer, comfortable as the primary engineer owning a product end to end and making decisions.
- Senior TypeScript and Node.js skills across modern frameworks and long-lived legacy codebases.
- Strong, current Angular experience and interest in modern Angular; the product currently uses Angular 16.
- Strong daily AWS operations: ECS Fargate, Lambda, SQS, Aurora (MySQL and PostgreSQL), SES, CodePipeline, and CodeBuild.
- Strong production debugging in systems with paying customers.
- Daily use of AI coding tools, particularly Claude Code, and experience building agent workflows.
- Experience in small or lean teams with broad ownership.
- Enjoys building products, has good product instincts, considers customer impact, handles billing carefully, and keeps production healthy.

## Nice to Have

- React.
- Email deliverability: DKIM, DMARC, SPF, warmup, blocklists, and sender reputation.
- Mailbox-provider APIs: Gmail API, Microsoft Graph, IMAP, SMTP, and OAuth.

- Public open-source work, personal agent/MCP tooling, or an active local developer community.

## Tools and Stack

TypeScript, Node.js, Angular, AWS (ECS Fargate, Lambda, SQS, Aurora MySQL and PostgreSQL, SES, CodePipeline, CodeBuild), and Claude Code.
