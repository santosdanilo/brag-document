## Interview Preparation

### Key Talking Points

1. Explain the MyTime payment-system migration as an incremental AngularJS/CoffeeScript to Angular/TypeScript modernization that preserved operations and improved test coverage.
2. Explain the GreenAnt migration as a second production AngularJS-to-Angular migration using Webpack dual-environment bundling and module-by-module delivery.
3. Use the GasHub Products API investigation to show systematic troubleshooting across request waterfalls, database queries, transactions, and network round-trips; warm latency reached approximately 132 ms, a 95.7% reduction.
4. Describe GasHub as recent Full Stack work: natural gas sales workflows, API contracts, adapter-layer integration, PostgreSQL, Drizzle ORM, Deno, layered architecture, and automated tests.
5. Explain the AWS Lambda PDF-generation microservice as documented serverless and deployment experience without implying broad AWS platform ownership.
6. Be precise about backend scope: Node.js, NestJS, Deno, PostgreSQL, and Java EE are documented; Go and Python are not.
