## Opportunity Summary

Jobsity is seeking a Full Stack Software Engineer for a role with an approximate 60/40 Frontend/Backend split. Angular is the primary frontend technology. The role involves building APIs, microservices, and data-intensive applications, and is focused on software development for data-heavy products rather than Data Engineering.

The engineer is expected to be product-minded, comfortable solving complex problems and collaborating across teams, and able to contribute across the full software development lifecycle within an existing distributed system serving millions of users.

## Requirements

- Conversational English level, approximately B2 or above.
- Residence in Argentina, Brazil, Mexico, or Colombia.
- Five or more years of Full Stack Software Engineering experience.
- Strong Angular and TypeScript experience; the role is approximately 60% Frontend and 40% Backend.
- Backend experience with Go, Python, Node.js, Java, or similar technologies; Go and Python preferred.
- Experience building REST APIs, microservices, and scalable web applications.
- Comfort working on data-intensive applications involving querying, modeling, or processing large datasets; the role is not focused on building data pipelines.
- AWS and modern cloud-native application experience.
